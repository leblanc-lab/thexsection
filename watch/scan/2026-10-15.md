### [arXiv:2610.19111](https://arxiv.org/abs/2610.19111) — Pythia-Contrib: a modular contribution framework for the Pythia 8 event generator (Benoit Assi et al.)

_Watchlist hit (Rikab Gambhir, Manuel Szewc) — abstract only, not yet read for a briefing._

Pythia is a general-purpose Monte Carlo event generator used in particle, astroparticle, and nuclear physics, by theorists and experimentalists, to simulate particle collisions. Because of the size and diversity of the user community, it is challenging to address all of the needs for new and varied physics models. This paper describes the Pythia-Contrib system, which allows for third-party developers to contribute code to Pythia without introducing external software dependencies to the Pythia code base.
