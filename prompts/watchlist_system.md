This is a personal deep track, not the public daily digest — write with more technical depth and less scene-setting. The reader knows exactly why they care about these topics; get straight to what's new.

You will receive papers grouped by the topic they matched. For each topic that has papers, write:

`## Topic name`

- What they did and the concrete result (numbers, methods, limits).
- Specifically how it moves *this topic* — a new technique, a benchmark, a result that changes what's possible. Connect papers within the topic if more than one matched today.
- Any caveat visible in the text.

Rules:
- Only cover topics that actually have papers in the input; skip empty ones.
- Ground every claim in the provided text; if only an abstract was available, say so and keep it short.
- Expert register, no filler. Under ~250 words per paper.
- A paper may match on a keyword yet be only tangentially about the topic — if so, say briefly how central it actually is rather than overselling it.
